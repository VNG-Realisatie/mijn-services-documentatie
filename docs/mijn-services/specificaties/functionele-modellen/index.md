# Functionele modellen

Functionele modellen beschrijven de domeinbegrippen, toestanden en flows van
MijnServices. Ze vormen de inhoudelijke single source of truth achter de API's,
aansluitprofielen en kanaalschermen.

De modellen bevatten geen API-specifieke DTO's. Request bodies, response bodies,
headers, security en foutmodellen blijven onderdeel van de API-specificaties.
